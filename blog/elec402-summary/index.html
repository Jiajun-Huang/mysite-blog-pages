A CMOS design has to produce the right logic levels within a timing budget and a power budget. These constraints interact: a wider transistor can drive a load faster, but it also loads the preceding stage and consumes more switching energy. The useful question is usually which part of the path limits the design, and what changes when that part is resized.

MOS capacitance and the load seen by a gate

A gate’s load includes the inputs it drives, the interconnect, and capacitance at its own output node:

CL=Cfanout+Cwire+Cself.C_L=C_{\mathrm{fanout}}+C_{\mathrm{wire}}+C_{\mathrm{self}}.CL​=Cfanout​+Cwire​+Cself​.

The fanout term comes from the next gates’ input capacitances. The self-loading term includes drain diffusion and other output-node parasitics. Keeping them separate helps avoid counting the same physical contribution twice.

For a long-channel device, the intrinsic oxide capacitance scales approximately as CoxWLC_{ox}WLCox​WL. How that capacitance is distributed among terminals depends on the operating region. In the ideal saturation model, the channel contribution to CgsC_{gs}Cgs​ is approximately 23CoxWL\frac23 C_{ox}WL32​Cox​WL and the intrinsic CgdC_{gd}Cgd​ is approximately zero. Physical overlap capacitance remains, so an intrinsic-channel formula cannot be used as the complete device capacitance.

When using a width-normalized capacitance such as Cˉg\bar C_gCˉg​, check its units first. If Cˉg\bar C_gCˉg​ is capacitance per unit width and length is fixed, an input driven by both NMOS and PMOS gates has approximately

Cin=Cˉg(Wn+Wp).C_{in}=\bar C_g(W_n+W_p).Cin​=Cˉg​(Wn​+Wp​).

This equation is also the conversion from a capacitance target back to transistor widths. A capacitance is a load specification; it is not itself a width.

Combinational delay and logical effort

Start with the capacitances

Sizing begins by identifying everything connected to the node being driven. Fanout count alone is insufficient: four small gate inputs can present a different load from four large ones. Wire capacitance also remains even if the receiving gate is resized.

A first-order delay model is t≈ReqCLt\approx R_{eq}C_Lt≈Req​CL​. Increasing device width reduces effective resistance roughly inversely with width, while increasing input and diffusion capacitance roughly in proportion to width. Enlarging every transistor therefore does not make a path arbitrarily fast. Each gate becomes a heavier load for its predecessor.

Normalize delay before comparing gates

Logical effort separates normalized stage delay into an effort term and a parasitic term:

d=gh+p,h=CoutCin,t=τd.d=gh+p,\qquad h=\frac{C_{out}}{C_{in}},\qquad t=\tau d.d=gh+p,h=Cin​Cout​​,t=τd.

Here ggg compares the gate’s input capacitance with that of an inverter having the same output drive, hhh is electrical effort, and ppp is parasitic delay. The technology-dependent τ\tauτ converts normalized delay to time. Course notes may express ppp using a separate parasitic ratio; that convention must be checked before substituting values.

An inverter has g=1g=1g=1 by definition. A complex gate’s logical effort is input dependent: match its drive resistance to the reference inverter, then compare the capacitance presented at the input being analyzed. Series stacks usually require larger transistors to retain the reference drive strength.

The sizing procedure is therefore: determine the path and its branches, compute FFF, compare feasible stage counts, balance the stage efforts, and convert the resulting capacitances into widths. Layout-dependent wire loads and input slew can require another iteration.

Pseudo-NMOS logic

Pseudo-NMOS uses an always-on PMOS pull-up and an NMOS pull-down network. With the pull-down off, the output approaches VDDV_{DD}VDD​. With the pull-down on, both networks conduct. The low output voltage is set by their current balance, so this is ratioed logic.

Reducing the device count can save area and input capacitance, but it does not remove the cost of a continuous current path. Noise margins, rise time and static power must be checked together.

Dynamic logic

Precharge and evaluation

A dynamic gate stores a voltage on a capacitive node. In the usual NMOS evaluation topology, precharge connects that node to VDDV_{DD}VDD​. During evaluation, the precharge transistor turns off and the pull-down network may discharge the node. If it does not discharge, the high value must survive until it is sampled.

A clocked footer can isolate the pull-down path during precharge. Device-count comparisons depend on the topology: an NMOS network with NNN transistors plus a precharge transistor and a footer uses N+2N+2N+2 devices before any output inverter or keeper is counted. That count is not a formula for every Boolean function or dynamic gate.

Why monotonicity matters

During evaluation, a discharged dynamic node cannot be restored by the precharge transistor. For an NMOS pull-down gate, inputs should therefore remain stable or transition from zero to one during that phase. A one-to-zero transition can leave the node discharged even though the final input combination should not discharge it.

The dynamic output can fall during evaluation. Driving another NMOS dynamic stage directly can consequently violate the next stage’s input requirement. An intervening static inverter turns that falling dynamic output into a rising signal. This dynamic/static combination is a domino stage. Its straightforward cascades implement non-inverting logic between stage boundaries.

Zipper logic alternates suitable NMOS and PMOS dynamic stages. The polarity and permitted transition direction must be checked at every boundary; alternating transistor types alone does not establish correct timing.

Charge sharing, leakage and clock coupling

Charge sharing occurs when a precharged output connects to initially uncharged internal capacitances. Ignoring leakage, threshold effects and other paths, conservation of charge gives

CLVDD=(CL+CX)Vfinal,Vfinal=VDDCLCL+CX.C_LV_{DD}=(C_L+C_X)V_{\mathrm{final}}, \qquad V_{\mathrm{final}}=V_{DD}\frac{C_L}{C_L+C_X}.CL​VDD​=(CL​+CX​)Vfinal​,Vfinal​=VDD​CL​+CX​CL​​.

The output can fall even without a complete path to ground. The relevant test is whether it stays above the receiving gate’s switching threshold with sufficient noise margin. Internal-node precharge and circuit restructuring can help, with additional capacitance and clock load as costs.

Leakage gradually changes the stored voltage. For an approximately constant leakage current over an evaluation interval,

ΔV≈IleakΔtCL.\Delta V\approx\frac{I_{leak}\Delta t}{C_L}.ΔV≈CL​Ileak​Δt​.

A keeper supplies a weak restoring current, but it can oppose a legitimate discharge. Keeper sizing is another contention-versus-retention tradeoff. A larger dynamic capacitance reduces voltage disturbance for a given lost charge, while requiring more energy and discharge current.

Clock feed-through is capacitive coupling from the clock into the dynamic node, including through the precharge device. Dynamic-gate reliability consequently depends on the clock waveform, the evaluation interval, internal-node charge and input transitions. A static truth table does not capture these conditions.

Power and energy

Separate energy per operation from power

Instantaneous power is p(t)=v(t)i(t)p(t)=v(t)i(t)p(t)=v(t)i(t), energy is E=∫p(t) dtE=\int p(t)\,dtE=∫p(t)dt, and average power is E/TE/TE/T. A lower average power can simply mean fewer operations per second. Energy per operation is the more useful comparison when the designs have different throughput.

Charging a capacitance from zero to VDDV_{DD}VDD​ draws charge CVDDCV_{DD}CVDD​ from the supply, so the supply delivers CVDD2CV_{DD}^2CVDD2​. Half is stored on the capacitor; the rest is dissipated in the charging path. Discharging dissipates the stored half. A complete charge/discharge cycle therefore dissipates CVDD2CV_{DD}^2CVDD2​ in the ideal capacitive model.

If α01\alpha_{01}α01​ is the expected number of zero-to-one charging events per clock cycle,

Pswitch=α01CVDD2f.P_{\mathrm{switch}}=\alpha_{01}CV_{DD}^2f.Pswitch​=α01​CVDD2​f.

Some texts instead define activity as the number of transitions in either direction and include a factor of one half. Always identify which events the activity factor counts.

Activity and clock gating

For independent values in consecutive cycles with probability ppp of a logic one, α01=(1−p)p\alpha_{01}=(1-p)pα01​=(1−p)p. Temporal correlation changes that result. Combinational glitches can also add charging events beyond what a cycle-boundary Boolean probability predicts.

Clock gating reduces clock transitions in unused sequential blocks. It can also reduce switching driven by those registers, but it does not eliminate switching caused by unrelated changing inputs, nor does it eliminate leakage. The clock-enable signal must be generated safely so that the gated clock does not acquire short pulses.

Capacitance, voltage and frequency

Smaller gates and shorter wires reduce switched capacitance. Their timing effects differ: shrinking a gate lowers its input load while weakening its drive. Floorplanning can reduce a wire’s load without relying on that same drive tradeoff.

Lowering voltage has a quadratic effect in the capacitive power model, but also reduces drive current and increases delay. Select voltage and frequency together under the required workload and timing constraints. Crossing voltage domains may require level conversion, especially when a low-voltage output cannot meet a high-voltage input’s required logic-high level.

PDP and EDP

Using the same operation boundary and defining average power over its execution time DDD, its energy is E=PavgDE=P_{avg}DE=Pavg​D. Under that convention, the power-delay product equals energy, while the energy-delay product is EDP=ED=PavgD2EDP=ED=P_{avg}D^2EDP=ED=Pavg​D2.

The convention matters. Multiplying a measured long-term average power by an unrelated single-gate propagation delay does not automatically give energy per useful operation. Likewise, reducing voltage cannot reduce energy without limit: leakage, longer runtime and functional voltage limits eventually matter.

Short-circuit and static power

During an input transition, both NMOS and PMOS devices can conduct simultaneously. The short-circuit energy is approximately

Esc=VDD∫Isc(t) dt.E_{sc}=V_{DD}\int I_{sc}(t)\,dt.Esc​=VDD​∫Isc​(t)dt.

Slow input edges can lengthen this overlap. The output load also affects the device voltages during the transition, so short-circuit current should be analyzed with the input slew and load together. A fast edge is not free if producing it requires a much larger upstream driver.

Static power includes subthreshold, junction and gate leakage, with contributions depending on process and bias conditions. It also includes sustained contention in ratioed circuits. Unlike the capacitive switching term, these currents can persist when the clock stops.

A useful power estimate separates switching, short-circuit and leakage contributions before choosing an optimization. Clock gating addresses activity; resizing changes capacitance and drive; supply scaling changes both energy and achievable speed. The largest term in the measured workload determines which change is worth making.

Sequential circuits and timing closure

A latch is transparent during one clock level. An edge-triggered flip-flop samples around a clock edge. Both require data to remain stable over a setup/hold interval; the distinction changes how time can be allocated between stages.

Let tcqt_{cq}tcq​ be launch clock-to-Q delay, tcombt_{comb}tcomb​ the combinational delay, and tsetupt_{setup}tsetup​ the capture setup requirement. With zero skew and no additional uncertainty,

Tclk≥tcq,max⁡+tcomb,max⁡+tsetup.T_{clk}\geq t_{cq,\max}+t_{comb,\max}+t_{setup}.Tclk​≥tcq,max​+tcomb,max​+tsetup​.

Define clock skew as tskew=tcapture−tlauncht_{skew}=t_{capture}-t_{launch}tskew​=tcapture​−tlaunch​. A positive value means the capture clock arrives later. The corresponding setup and hold checks are

Tclk≥tcq,max⁡+tcomb,max⁡+tsetup−tskew,T_{clk}\geq t_{cq,\max}+t_{comb,\max}+t_{setup}-t_{skew},Tclk​≥tcq,max​+tcomb,max​+tsetup​−tskew​, tcq,min⁡+tcomb,min⁡≥thold+tskew.t_{cq,\min}+t_{comb,\min}\geq t_{hold}+t_{skew}.tcq,min​+tcomb,min​≥thold​+tskew​.

Positive skew helps setup but makes hold harder under this convention. Setup constrains the longest path; hold constrains the shortest path. Reducing clock frequency can help setup, but it does not repair a same-edge hold violation. Practical checks also include jitter, clock uncertainty and variation margins.

For latch-based designs, transparency permits time borrowing, but the analysis must include the latch opening and closing times and the following stage’s budget. Borrowed time is taken from another part of the path.

What to carry into a design problem

Begin with the required function and legal signal transitions. Identify the physical loads, estimate delay, and size the path against its timing constraint. Then evaluate switching activity and energy using the actual workload. Dynamic and ratioed logic add retention or contention checks that static CMOS timing alone cannot supply.

The recurring constraint is that an improvement at one node changes the work done elsewhere: a larger gate loads its predecessor, a keeper opposes discharge, and a slower low-voltage path spends longer leaking. The final circuit has to satisfy logic levels, setup and hold, and power limits at the same time.
